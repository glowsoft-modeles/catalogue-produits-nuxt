# Catalogue de produits Nuxt

Un catalogue filtrable, lu depuis un fichier JSON du dépôt.

Modèle de départ Bastide (`catalogue-produits-nuxt`), écrit par Glowsoft. Il se construit et se déploie sans modification ; la campagne hebdomadaire le construit avec des valeurs d'essai.

## Variables

Aucune variable requise.
